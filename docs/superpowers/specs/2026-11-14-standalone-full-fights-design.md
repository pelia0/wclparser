# Standalone full-field fight archives

User supersedes previous raw-response design: reset the entire collection again; no permanent raw data; preserve every game-event field in a self-contained compressed archive; retry Too Many Requests pages; make packing fast. No migration of the small current collection is wanted. Keep authentication/browser profiles. Leave server stopped after installation unless user asks otherwise.

Use WCLF version2 with independent Zstd level9 sections: derived summary, full canonical event records, supplemental replay records, full report metadata and compact provenance/page metadata. Dynamic columnar encoding preserves every key, nested value, null versus absent, integer precision and decimal numbers; unknown fields need no schema update. Missing fields use an internal MessagePack extension distinct from JSON values. Verify section SHA256 and full decoded event equality before committing a fight as packed. No serialized HTTP body text, ranking HTML, error pages or duplicate event payloads outside the fight file. Transient network buffering is in RAM, bounded to active work and bounded report metadata caches; release event snapshots after a verified write or failed/cancelled attempt. A complete fight remains readable/exportable after its downloader and buffers have been destroyed.

Retain legacy readers for compatibility, but the app never creates data/raw or a raw manifest database. Source/full-event export reads the standalone file, not a sidecar store. Data stays ignored by Git. Existing download pagination and replay remain full-field; 429 applies shared cooldown and repeat of the SAME ranking page, never certifies an error page as empty. No additional concurrency that amplifies rate limiting. JSON endpoints already have bounded429 retries; browser navigation/rendered AJAX error detection must match them.

Reset old catalogue, scan state and all recognized fight/raw/staging collection paths only after full verification; preserve credentials and browser profiles. No conversion required. Do not auto-resume collection. Fix terminal failures visibly; do not claim a full uploader combat-log file is available through WCL.
