# Lossless historical WCL archive

Approved scope: preserve every received source field for historical TauriWoW bug reports; restart collection from an empty catalogue; default raid discovery to two pages per specialization. Keep Legion M+ season 5 and all raid difficulties/partitions. Preserve authentication and browser profiles. Fix the supplied duration, queue completion/retry, explorer pagination, portability and documentation findings.

The authoritative archive stores original decoded HTTP response bodies (browser fetch text encoded as UTF-8; httpx response content), before JSON parsing or event normalization. SHA-256 addressed Zstandard blobs deduplicate identical bodies; a SQLite manifest retains request URL/method, GraphQL request variables, capture time, response status, report/fight attribution and provenance. Tokens/cookies are not part of request metadata. Writes are atomic and verified. Unknown fields, nulls, numeric precision and original event ordering survive because bodies are retained verbatim. Browser-rendered ranking HTML is explicitly labeled as a DOM snapshot.

Canonical paginated event responses are mandatory. Replay segments may supplement them but cannot replace them. Malformed responses, GraphQL errors and non-advancing cursors fail collection instead of certifying a partial archive. Original report metadata is retained once per content hash. WCLZ remains a disposable analysis cache, explicitly distinguished from the source archive. Source manifests and original bodies can be exported through the local API. No claim that WCL exposes the original uploader's complete combat-log file.

Failures have persistent attempt counts/reasons and bounded retries per run; starting again permits retrying failed work. Empty batches cannot mean completion while pending work remains. Terminal failures are reported as incomplete. Viewer defaults to packed fights and has stable limit/offset pagination. Exact duration is committed from fight boundaries. Paths resolve relative to the repository; dependencies are locked from the verified runtime.

Reset happens only after tests and review: quiesce the local server; remove old fight archives, derived catalogue/scan history and source archive if any, confined to D:/wowlogsparser/data. Preserve auth_session.json and browser profiles. Restart the local viewer idle; do not start a new harvest automatically. Existing dirty source changes are preserved; no commit/push is authorized.
